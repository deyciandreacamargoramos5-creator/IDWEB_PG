✈️ Xen Airlines
Xen Airlines es una plataforma web de gestión y reserva de vuelos diseñada para simular la experiencia comercial de una aerolínea moderna. El sitio permite a los usuarios buscar itinerarios en tiempo real filtrando por origen, destino y fecha, registrarse en el programa de membresía de viajero frecuente y realizar compras de boletos. Además, integra un sistema de autenticación seguro y un panel de usuario dinámico.

Link del sitio web hospedado: https://xenairlines.pythonanywhere.com 

---
🛠️ Tecnologías utilizadas
HTML5 y CSS3: Para la estructura semántica, el diseño visual corporativo y la maquetación adaptable (Responsive Design) de las vistas.
* JavaScript (Vanilla): Para la manipulación del DOM, validaciones de formularios en el frontend y consumo de datos asíncronos (Fetch API) para conectar la interfaz con el backend sin recargar la página.
* Python (Flask): Framework utilizado para el servidor backend. Gestiona el enrutamiento (API REST), la lógica de negocio (búsqueda de vuelos, autenticación) y la conexión segura con la base de datos.
* SQL (MySQL): Base de datos relacional (alojada en PythonAnywhere) para la gestión, persistencia y consulta de tablas relacionales: usuarios, vuelos y compras.
